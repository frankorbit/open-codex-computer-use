# 编辑范围与菜单目标发送前校验

用户要求修复弹层与后台字段混写、失效菜单项以及保存核验不完整；禁止重放已经发送的操作，保留权限、取消和超时停止边界。

- 新增 `AXInputScope.swift`：只读依赖、有限祖先遍历、进程/父子成员关系核验、当前编辑范围和菜单项校验。没有自动保存、激活、按键补救或重试。
- `ComputerUseService.swift` 在 set_value、菜单项 AX/显式鼠标/secondary action/坐标命中 AX 分支接入校验，普通控件不经过菜单预检。
- `AccessibilitySnapshot.swift` 保留完整背景树与原有索引，同时提示当前弹层编辑范围和保存后重开核验。
- `AXActionExecution.swift` 允许发送前校验，已发送的失败仍抛出未知效果，不进入后续候选或鼠标 fallback。
- 13 项新增原生回归覆盖嵌套范围、多窗口、脱离父节点、菜单分组、失效/跨进程/不可读目标、取消/权限和单次写入。

验证：611 XCTest（8 项实机跳过）与 68 Swift Testing 通过；格式整理后 42 项输入相关回归通过。新增 Swift 文件格式和严格 lint 通过。配套 Web Runtime 252 项通过，包含 owner-guard 与 Worker 入口；保存重开测试使用模拟原生响应，不能代替真实提醒事项验收。

Review：无自动重放或停止规则放宽。预检与输入间仍存在系统竞态；失败继续停止。AX 无法完整表达的自绘弹层和慢响应应用需真机确认。当前签名 App 与 Web native pin 尚未包含本次原生改动。
