# 工具栏弹层的后台事件与焦点生命周期

## 用户诉求

手动点击工具栏颜色箭头能够打开并选择颜色，而 Agent 绕到 Font 设置；要求用 Today 自身链路对照工具栏点击、弹层发现、截图和结果确认。

## 改动

- 普通 SkyLight 左键单击仅投递目标处 move/down/up，每个事件只走 SkyLight PID 通道；双击保留 primer 与 click-state 序列，右键仍是单对目标事件。
- 后台普通左键准备目标 key window；其中普通单击在 key record 后等待 100ms 供应用处理焦点，不按输入速度缩放，不用于双击、右键、前台点击或弹层续点。dispatcher 的有界菜单焦点状态最多保留 30 秒，允许只读截图与后续 popup-token 点击复用；无菜单时立即结束，无 App 名字特判。
- 清理验证进程身份和用户前台激活，使用单进程 owner、代际 timer 与派发锁隔离其他会话和键盘动作。失败保持不重放，接收者与快照校验不变。
- 策略和参数校验仍在任何观察与执行之前。只读 get_app_state 不进入菜单等待循环。
- 新增等待结束后复核根窗口几何和进程身份；改变时在鼠标投递前拒绝，不向复用 PID 清理旧焦点。
- 更新弹层 move 后失效的测试；已提交 down 的配对 up 与未知结果不重放覆盖保留。

## 证据与验证

- Today Helper 本地最终构建两步打开工具栏色板、点击 More Fill Colors 进入 Colors，然后 Cancel。两次输入前后前台 PID 与真实指针均保持不变；未修改文档格式。
- 释放合成焦点会使后台色板关闭。试验中保留焦点后菜单持续到 30 秒上限，过期的 popup 凭证被拒绝，未重放输入。
- 独立 Chrome 真实 fixture 验证单击一次、右键一次、双击一次，以及前台焦点、真实指针和窗口顺序保持，1 项通过。
- 最新全量 Swift 测试：503 项 XCTest，7 项显式跳过、0 失败；另 50 项 Swift Testing 通过。覆盖 key 准备先于 down、弹层复用不重新等待、普通状态读取不等待，以及前台、双击、右键不增加该等待。复审后追加目标在等待期间失效与 PID 复用用例，受影响的 42 项测试通过（1 项 GUI 显式跳过）。追加保护后的 Helper 再次打开 File 并 Esc 关闭；该次用户指针变化，指针保持结论沿用前一组静止对照，不把移动样本混入。
- 新增文件通过 SwiftLint 与 SwiftFormat；git diff --check 通过。文档检查通过；make check-repo 因仓库原有缺失的 CI/issue 模板与编辑器配置失败，本轮不补无关模板。
