# 日期与窗口启动证据修复

用户要求：修复真实编辑操作中的错误，保留权限、取消、超时和不重放边界，再进行 lane 与签名 App 验收。

- CFDate 使用固定语法及日期分量回验，拒绝非法日期、DST 缺失/歧义时刻；显式时区仍受支持。
- 时间单独输入保留原日期，日期单独输入保留原时刻；非 CFDate 值仍按原字符串写入。
- 启动 3 秒等待不变。超时后只读复查上限 200ms；必须 AX 明确为空、CG 无窗口且结果及时，才允许一次后台 reopen。
- 读取失败、迟到结果、权限拒绝、取消、进程改变不会补发；挂起初始化继续阻止重复打开。
- 未修改点击、鼠标路由、截图坐标、输入回放或权限策略。

验证：原生完整 XCTest 598 项（8 项环境相关跳过），Swift Testing 68 项通过；定向日期/启动 23 项通过。实际签名 App 与 Today 端到端验收另行记录，不以单元测试替代。
