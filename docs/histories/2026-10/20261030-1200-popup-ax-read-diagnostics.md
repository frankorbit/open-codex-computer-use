# 弹层 AX 读取失败诊断

## 用户诉求
继续未完成的实机复测，遇到问题先分析；不重复已发送操作，不放宽停止规则。

## 本轮证据与边界
备忘录菜单点击只发送一次且 AX 返回成功，随后弹层观察返回不完整。现有 axWindowsUnavailable 无法区分准备失败、AXCopy 错误与总预算耗尽，不能据此断言需要延长超时。

## 改动
- 在既有一次属性读取上记录固定失败阶段、AX 原始错误码、应用 PID、绑定窗口 ID 和剩余预算。
- 属性名限定白名单，不记录 AX 值、窗口标题、笔记内容；不增加系统查询或重试。
- 保持原先 prepare → 单次 copy → 截止检查的短路顺序；原 25ms 单次 AX 限制、200/800ms 观察预算、权限错误与 token 发放规则不变。
- 回归覆盖真实权限错误、不可完成、无值、准备失败、晚到成功、合法空窗口列表；原弹层预算/作用域/单次输入回归继续执行。

## 验证
定向 28 XCTest 与 6 Swift Testing 通过；完整串行运行 723 XCTest（8 skip）与 77 Swift Testing 通过。默认并行运行的 3 条既有预览计时测试出现 4 个断言失败，保留日志，不改生产计时规则。SwiftFormat、改动文件 SwiftLint 和文档检查通过。签名 App 的新只读采证待完成。
