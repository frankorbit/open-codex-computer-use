# 后台输入与实时焦点对齐

## 用户诉求

修复后台点击、聚焦、输入链路，并对照 OCU 上游实现和官方 Codex 多案例实测复审。

## 改动与动机

- 元素/坐标自动鼠标兜底共用窗口验证与路由，默认左单击和双击使用上游 sky_click。auto 不执行 activation-only 窗口抬升。
- background 策略与显式前台点击授权分开，点击授权不扩大滚动/拖拽权限。
- auto 键盘复用上游 sky_key；文本实时检查目标 PID、窗口、输入框、可编辑状态，合成 key 状态建立后及每个文本分块前再次校验。
- 删除缓存 focusedElement 上的 AXValue 拼接，保留键盘插入点和选区语义；显式 set_value 不变。
- 焦点摘要不再因为树裁剪而丢失，树外焦点不伪造元素索引。
- 键盘工具加入关联诊断，不记录正文或按键内容。
- 复审覆盖菜单查询期间切换窗口、未知菜单属性、长文本中途换焦点与组合输入框。
