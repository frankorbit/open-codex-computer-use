# 完整窗口截图覆盖与坐标前置校验

## 诉求

修复部分出屏截图与完整窗口坐标换算不一致的问题；覆盖多屏、缩放和错误点击参数，保持停止规则且不重放已发送操作。

## 实现

- `WindowCaptureGeometry` 统一完整窗口比例检查、捕获选择、SCK 输出尺寸及坐标校验。
- 单屏完整包含窗口继续使用硬件截图；出屏、跨屏及异常硬件图片使用一次独立窗口 SCK 捕获。
- SCK 使用过滤器自己的内容尺寸和缩放，拒绝已经移动、尺寸不匹配的窗口，不混用 AppKit 屏幕坐标。
- 捕获失败不交付部分图，保留 AX 信息；主窗口坐标点击、单次前台点击及共用坐标转换在发送输入前拒绝无效截图/坐标。
- Today 宿主 JS 在 native 调用前拒绝错误 click target；保留正确数字/字符串元素编号、坐标及已有 popup token 契约。宿主修改独立于本仓库。
