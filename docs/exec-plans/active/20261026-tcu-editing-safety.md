# TCU 编辑可靠性修复

状态：实现与回归验证中。

## 目标与边界
- 严格校验日期，不将非法日期或 DST 跳时默认为另一个时间；CFString 输入语义不变。
- 启动超时不证明无窗口；只有新鲜、有界、明确的 AX 与 CG 无窗口证据才能补发一次后台 reopen。
- Runtime 的 find 不将部分遍历当成唯一性证明；保留 query 的只读部分结果。
- 指引去除自动开关重置，明确实际保存、范围确认、重开回读，以及新窗口观察边界。
- 不改点击机制、不放宽权限/取消/超时规则、不自动重放业务输入。

## 验证
- 日期转换、窗口等待、身份变化、取消和真实权限拒绝单元测试。
- Runtime owner-guard 完整入口：部分查询后不发送输入，先前发送的动作不重放。
- Swift 质量检查、完整自动测试、签名 App 构建；Today 实际链路复测独立提醒事项、Numbers、Calendar 数据。
