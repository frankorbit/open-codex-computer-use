# 原生文件列表单击验收

## 证据和目标

Numbers 打开面板的文件行坐标单击投递一次后没有选中，Open 仍禁用。映射点落在正确行；这不证明 SkyLight 输入已生效，也不证明其失败原因。Codex 在另一个独立样本使用元素单击能选中文件并启用 Open。

端云指引把带 Open 的原生列表项一律导向坐标路径，与已有 AXSelectedChildren 优先实现冲突。原生选择发出后，部分 AX 错误返回 false，还可能继续尝试 AXOpen；必须修正，不能仅更改提示词。

## 范围与约束

- 原生左键单击保留列表选择优先；选择发送后任何错误都抛出，不进入打开或鼠标回退。
- 文件项暴露 AXOpen 且属于列表时，选择能力缺失也必须在发送前拒绝，避免变成打开动作。
- 普通非列表、非可选择列表、WebArea、右键和双击路径保留；真实权限错误不吞掉。
- 同步 Web runtime、Cloud TS 与 Go 入口指引；不改点击坐标映射、SkyLight 事件、停止规则或重放策略。
- 不重试已发送的原文件点击；修复先在独立样本验收，原保存额外授权仍未使用。

## 验证

- 原生回归：一层/嵌套文件项选择、发送前不可用、发送后全部 AX 错误仅一次尝试、非列表/WebArea边界和遍历上限。
- Web Runtime 文档契约与完整测试；Cloud 完整聊天入口验证新指引与禁止重放。
- 全量原生测试、静态 review；提交 fork 后更新 pin，签名 App 和 lane 验收后按题目顺序继续。
