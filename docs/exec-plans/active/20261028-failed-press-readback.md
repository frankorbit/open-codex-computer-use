# AXPress 失败后的只读证据

## 目标与边界
保留已发送操作的原始失败，追加当前窗口的只读诊断，避免把 AX 通用失败误认成零副作用。禁止重放、换路输入、放宽权限/取消/超时停止规则。

## 实现
- 仅原始 AXButton 单次 AXPress 返回 -25200 时进入诊断；多击、后代、菜单项、坐标、权限/超时均保持原行为。
- 同一调用内最多一次 readOnly build，校验取消、进程和绑定窗口；失败作为附加信息，原错误始终 isError=true。
- 不发布诊断快照输入缓存或弹层 token；失效该应用索引。Runtime 使用当前 owner 输出已有内容，不再发原生请求。
- 完成但无候选的弹层观察与 incomplete 明确区分，仍不能猜坐标或绕过输入校验。

## 风险与验收
诊断有额外一次只读构建成本，受现有请求超时控制；不增加成功操作开销，不设置重试。Swift MCP 入口与 Web owner-guard 入口覆盖已生效/未生效、观察失败、权限/超时/取消和迟到输出。
