# 后台弹层接收者与文稿身份

## 目标与证据

Numbers 核对文稿路径时进入标题栏位置弹层；sky_click 在发送前被桌面鼠标接收者校验拒绝。现有日志没有实际 receiver ID，不能倒推出当时遮挡窗口。源码确定普通后台坐标输入与弹层使用了不一致的接收者契约；Codex AX 观察可直接显示文稿 URL，而本实现缺失。

## 范围与约束

- sky_click 使用凭证绑定窗口、同应用上层窗口与 Space 校验；global 仍要求精确桌面命中。
- 保留 token 单次消费、30 秒 TTL、几何/身份/可见顺序、move 后复验、无自动重放与权限停止。
- AXWindow 只读展示 AXDocument；不更改输入、保存或模型停止规则。
- 不重新执行原来失败的点击；独立样本对照，再用新观察继续尚未发送的单次保存。
