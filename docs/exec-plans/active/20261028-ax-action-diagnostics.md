# 普通 AX 动作诊断与提醒事项验收

## 证据与目标

提醒事项行 Details 和随后 Edit Details 按钮均返回成功，但后续 AX、截图及只读弹层观察没有确认详情打开。普通 AX 路径缺少发送记录，因此外围 click 日志不足以判断具体动作与候选来源。Codex 在独立测试事项的一次点击报错后，观察到详情已打开；不能从返回码推断界面效果，也不能据此重放动作。

## 范围与不变量

- 给普通 AX 与 secondary action 的实际调用增加脱敏的动作类别、候选来源、attempt 和返回码。
- 不记录应用文本、自定义动作正文或控件内容，不改变动作选择、时间预算、输入次数和异常传播。
- 未发送不记录 attempt；发送后的成功不代表业务成功，错误继续立即停止，不增加候选或鼠标回退。
- 原失败目标不重放；诊断制品使用另一个独立测试目标核验。
- 不改 Cloud、权限、取消或停止规则。

## 验证

- [x] 单次发送、未声明动作、预检拒绝、错误终止和脱敏回归。
- [x] 完整入口与完整串行原生测试、静态 review。
- [ ] fork 提交推送、Web pin 验证、签名 App。
- [ ] 独立目标实机采集实际动作证据，再决定是否需要行为修复。
