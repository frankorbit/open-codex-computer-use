## 现场与证据边界

Numbers 输入与 Return 已独立回读成功，但后台 File 的 Save / Rename / Move To 不可用，没有发送保存。后续 Codex 对同一文稿展开 File 时，AX 中这些命令可用；截图不可用。这是不同时间的对照，不宣称掌握 Codex 内部实现，也不能单凭对照证明唯一根因。
