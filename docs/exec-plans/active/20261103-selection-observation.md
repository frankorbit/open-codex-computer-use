# 选中状态证据修复

## 目标与范围

修正 Finder 文件容器没有自身 `AXSelected` 标记时被误判成未选中的问题。对齐 Codex 对外的选区汇总语义，不推测或复制其未公开内部实现。

## 证据与决定

- 既有实机记录中，Today 文件选择返回 AXSelectedChildren -25205 后停止；Finder 状态栏与既有预览已显示选择结果，Codex 只读输出另有 Selected 节点。
- 本轮 Codex 只读检查时，现场已变为桌面选中了另一测试文件；没有重放昨晚的文件点击。Codex 仍输出 selected 标记和 Selected 汇总；不能将今早现场当作昨晚同一状态。
- 旧完整快照只读自身 AXSelected，query 也未合并父容器 AXSelectedChildren。缺失布尔值和 false 必须区分。
- 父容器明确列出的、当前遍历实际遇到的成员是正向证据；不在采样中不能推导 false。自身 false 与父成员冲突时保留冲突，不选边。
