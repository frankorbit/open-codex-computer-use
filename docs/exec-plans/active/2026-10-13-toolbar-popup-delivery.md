# 工具栏打开弹层的投递与观察对照

## 目标

定位普通工具栏点击后没有得到可用弹层、Agent 随后切换复杂路径的问题。预览透明度修复已独立发布。本轮对照 Today Helper 的实际输入、WindowServer 候选及返回图像，不以点击回执代替 UI 效果。

## 范围与约束

- 沿用当前分支；不修改云端路由、记忆或文档内容。
- 只打开、观察和关闭工具栏颜色菜单与应用内 File 菜单。
- 对照现有双通道与单通道，序列和通道分别隔离；已投递未知结果不能自动重放。
- 保留窗口身份、几何、接收者校验与后台执行边界。不按应用名字特判。
- 实验开关只存在本地临时构建，不进入生产 API。

## 验证

1. 用 Today 打包 Helper 记录基线截图、输入诊断及弹层候选。
2. 用相同 Today Helper 源码连接待测 Kit，逐组对照。
3. 以截图和候选验证打开，再显式关闭；独立检查前台和真实指针不被抢占。
4. 按证据确定修复，补普通点击、双击、右键及失败不重放回归；运行必要的真实 fixture 回归。
5. 全 diff 复审并记录交付边界，不把本地 Helper 验证称为云端 Agent 验收。

## 本轮证据与状态

- 预览透明度修复已在远端，未重复提交；本轮未更新 Today pin 或安装包。
- 相同输入位置对照：双通道、primer、key-window 准备、焦点释放分别隔离。前台 WPS 的混杂样本不用于证明后台成功。
- 固定非 WPS 前台和真实指针时，准备 key 后色板在约 40ms 出现，释放 synthetic focus 后约 40ms 消失。
- 去除普通单击 primer，采用单通道并维持有界焦点后，色板在后台持续至 30s 上限；在有效期内点击 More Fill Colors 能打开 Colors，再以 Cancel 关闭。没有改变文档颜色或导出文件。
- 初始 File 后台 SkyLight、AX 和 app_post 点击无菜单；增加点击后的候选等待到 300ms 无改善。后续隔离发现，后台 key record 后直接 down/up 会失败，提前等待 100ms 后成功；恢复零等待再次失败，加回等待再次成功。另一实验延长 down 也成功，但不采用，避免改变按键节奏。
- 正式候选仅在后台普通左单击 make-key 后增加 100ms，不缩放、不重放；实际 Today Helper 的 File → popup-token Export to PDF → Export PDF File → Cancel 路径已通过；静止复测的两次点击前台与真实指针保持不变。20ms 样本虽打开菜单但有用户鼠标移动，未用于无干扰验收。
- 这说明入口可用性确有输入层差异；不能只归因于历史记忆或模型不了解入口。

## 验证与剩余事项

- 完整 Swift 测试通过，实际计数见本轮 history；隔离 Chrome 的真实单击、右键、双击和前台焦点/真实指针保持回归通过。
- 添加焦点复用、超时、窗口/PID 改变、用户激活、会话交接、失败清理回归；弹层凭证过期与接收者变化仍在 down 前拒绝。
- 颜色与 File 均已有本地 Helper 后台修复候选；验证边界是打开菜单与进入下一级对话框，没有实际修改颜色或导出文件。最终 Agent 是否选择常规路径仍需集成验收。
- 未执行新修复的依赖发布、Today pin 更新及云端 Agent 全链路验收。

## 连续交互复审后的修正

- `list_apps` 不再被当作 app=nil 的目标切换，也不获取/释放其他会话的菜单 owner；仍消费旧输入凭证，不放宽前台单次授权约束。
- 连续动作完成后即时复核原弹层与本动作新增候选，不再无条件失焦。保留原到期时间与进程身份，旧 timer 通过代际隔离；原先无关的同应用窗口不能续租。
- 失败、弹层关闭、根窗口变化、PID 复用与用户激活仍清理；无 lease 的普通动作不增加准备或轮询。
- 本次新增验证覆盖列表查询成功/失败、跨会话查询、连续动作及回读、弹层替换、无关窗口排除、原期限、失败不重放和授权消费。真实第三方应用的菜单滚动/设置值链路仍需集成验收，不能用注入测试替代。

## 等待机制的取舍

- 100ms 在后台普通左单击的 make-key 后；120ms 是点击后的候选等待上限，有候选可提前退出，尚无候选则仍按期释放。两者不代表系统就绪或成功确认。
- 除每次最多约 220ms 额外等待外，还包括 WindowServer 枚举开销；等待占用输入互斥锁，会延后同 Helper 的其他调用。普通观察没有新增固定等待，但并发时仍可能等待该锁。
- 应用内部会收到合成激活/key/失焦，可能触发其编辑提交、选区或弹层生命周期；不会据此宣称零副作用。前台与真实指针不应由该路径移动，但用户可在等待期间改变目标，所以保留重验与未知结果不重放。
- 暂保留已验证的通用时序；没有可靠就绪证据前，不用立即重试、App 名字特判或过早缩短等待换取速度。
