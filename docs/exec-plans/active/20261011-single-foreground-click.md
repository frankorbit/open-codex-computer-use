# 单次前台点击

目标：保持 Today 的严格后台默认，仅允许宿主启用的单次左键兼容入口。不得改长期 helper 的环境或普通 auto、键盘、滚动、拖拽策略。

方案：ComputerUseService 构造时明确启用；最近一次显式观察提供同 app、30 秒内资格；dispatcher 在校验前消费资格。执行前使目标输入快照失效，校验当前窗口身份，激活指定窗口，重验接收者、几何和遮挡，再投递一次 HID 左键。传参资格只沿此调用栈传入点击准备和点击原语，不覆盖 ExecutionPolicy。

输入后不自动重试或回读。调用方必须重新观察；发送/提交/删除不能以此入口重试。控件语义由 agent 判断，purpose 是使用契约，不能证明目标控件身份。

验证：默认宿主拒绝；资格过期/跨 app/被其他动作或错误参数消费；激活后接收者失配；成功或异常后普通全局仍拒绝；Today JS 未知参数、未知效果不重放；现有后台回归。真实 App/lane 验收与本地自动测试分开。
