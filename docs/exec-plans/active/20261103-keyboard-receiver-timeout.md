# 键盘接收者校验与观察超时隔离

## 目标与范围

修复输入接收者继承观察短超时的问题。保留实时窗口一致性、可编辑性校验、取消、失败停止和禁止重放；不修改点击、后台焦点准备、菜单派发或云端规则。

## 证据

- Numbers 第8题 Return 在 synthetic key-window 准备后失败，未出现键盘提交日志；运行版本的 requireEditable=false 分支只读取 AXFocusedWindow。
- resolveTargetWindow 对 system-wide AX 对象设置 0.1 秒超时。SDK AXUIElement.h 明确此设置影响当前进程全局默认值，新的接收者 App 元素未设置自身超时。
- -25204 可代表消息失败或未及时响应；代码中的超时串扰已确定，不能据此断言此次操作仅有这一原因。

## 决策与风险

- 在严格 KeyboardReceiver.read 路径使用现有 axInputMessagingTimeout 预算，整个校验共享截止时间，逐次读取显式设置剩余预算并恢复对象设置；不修改全局默认超时，不重试查询或输入。
- 不把无法读取当作校验通过，不使用旧快照焦点或改 route；保留失败回执未知结果语义。
- 增加固定 AX 属性、结果码和耗时诊断，不记录属性值或输入正文。
- 接收者慢响应时可能比旧有继承的 100ms 等待更久，上限为现有 2 秒预算；单次同步 AX 调用仍只能在返回后检查取消。
- 上一轮 Finder paste 未提交改动独立保留。
