# 实时预览主窗口隔离

## 目标与约束
修复系统独立窗口流包含父子窗后，再叠加独立 popup 导致的重影。只改本地预览；不改模型图片、输入坐标、预算、权限、取消或停止规则；不重放已发送输入。

## 方案
- 完整位于一块显示器且可见的 root：精确窗口 ID 的 display-bound 流，关闭子窗口，按该显示器本地坐标裁剪。popup 继续独立叠加。
- 跨屏、部分离屏、隐藏或其他 Space：保留 desktop-independent 流，等比呈现系统窗口组；不再额外叠加 popup，也不显示未经证实映射的虚拟光标。不会把裁剪图冒充完整 root。
- display-bound 流的移动、尺寸、可见性及显示器变化导致重新绑定；过渡旧帧不得贴到新几何。

## 验证
配置/几何、隐藏/跨屏退回、移动旧帧拒绝、复合图像顺序；原预览生命周期、键盘、停止测试。全量 Swift 测试与改动行格式检查。提交 fork、Web pin、签名 App 后只读实机核验重影，再继续既有复测。

## 状态
主窗口隔离与透明背景已交付，用户截图确认无重影/黑底。新增问题为系统标题栏关闭钮仍停在union画布的透明左上角。改为主窗区域内侧的本地收起控件，跟随几何与缩放；不改采集、输入和停止规则。回归与新签名外观待验收，其余复测顺序保持。
