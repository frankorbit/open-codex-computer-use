# 当前焦点所在行的观察完整性

## 证据与范围

提醒事项标题进入编辑后，AXRow 仍未选中。当前 renderer 无条件摘要未选中行，隐藏标题、备注、日期和详情按钮，并报告焦点位于树外；独立 Codex 观察能显示这些控件。活动菜单观察不完整是另一个未证明根因的问题，不据此修改点击或预算。

## 方案

每次构建 renderer 时只沿当前焦点的 AXParent 向上读取，最多沿用树深度且不超过64层。同 PID、无环且最终到达当前绑定窗口根才保留路径；仅这条路径上的未选中行正常渲染。其他未选中行继续摘要，已选中行沿用原行为。没有新的输入或重试，原节点/深度/文本预算不变。

## 验证

- 定向8项：未选中编辑行、其他行压缩、嵌套行、选中行、其他窗口、PID不符/不可读、环/断链、深度边界、焦点变化。
- 原生完整回归699项（8skip、0fail）及68项Swift Testing通过。新增文件严格lint与文档检查通过；renderer只检查变更行，无新增lint违规。Runtime行为无改动。
- 当前证据为代码与定向测试；签名App中的行观察及第3题完成验收待进行。

## 限制

焦点路径读取失败时保持原摘要，不授权输入，也不声称焦点已找到。此改动不改变菜单发现/弹层捕获、点击、权限、取消、超时、已发送操作不重放等规则。
