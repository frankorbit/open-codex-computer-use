# 编辑范围与瞬态菜单输入保护

## 目标
- 活动 AXPopover/AXSheet 存在时，阻止 set_value 修改其背后的字段。
- 菜单项动作发送前验证当前角色、所属进程及父菜单成员关系。
- 已发送动作失败仍保持未知效果，不自动 fallback 或重放；权限/取消规则保持。
- 提交后重新打开才可报告持久化成功，覆盖 worker + owner-guard 回归。

## 实施
- 原生有界只读预检，真实 AX 适配与纯读取依赖分离。
- 不隐藏背景观察、不更改键盘/鼠标发送路径、不引入自动保存或重试。
- runtime 指引说明活动编辑范围、冲突回读和错误语义；回归覆盖未发送和已发送失败。

## 验证
源码实施和 review 已完成：原生完整运行 611 XCTest（8 项实机跳过）及 68 Swift Testing 通过；随后格式整理后的输入范围/动作/坐标点击定向回归 42 项通过。Runtime 完整 252 项通过。新增 Swift 文件通过 SwiftFormat 与严格 SwiftLint；既有大文件只格式化变更行。真实 App 仍需提交 fork、更新 native pin 后重新构建验收。

## Review 边界
- 只新增 set_value 编辑范围预检及 AXMenuItem 输入前校验；不修改键盘、滚动、拖拽、坐标转换、菜单发送策略、云端停止规则。
- 普通动作继续使用原有默认路径；嵌套弹层、其他窗口、菜单分组容器、真实权限拒绝和取消已覆盖。
- 预检读取每次最多 350ms，单次 AX 消息最多 50ms；不是固定等待，不调整实际输入原有 2s 消息超时。AX 读取不完整/过慢时保守拒绝，需真机观察误拒率。
- 校验与系统输入并非原子操作；菜单在其间消失仍可能失败，保持未知效果并停止，不补发。
- 编辑范围依据已观察到或当前焦点祖先中的 AXPopover/AXSheet；无法把未暴露 AX 语义的所有自绘弹层视为已覆盖。
- 保存重开规则属于运行时指引与显式工作流契约；测试验证状态和错误传播，不冒充模型策略评估或真实 App 的持久化验收。
