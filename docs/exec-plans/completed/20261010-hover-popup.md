# Hover 弹层观察与输入闭环

## 目标与范围

修复 hover 回读只捕获主窗口的问题。补充经筛选、复核的目标 App 弹层独立截图，主窗口坐标契约保持不变。沿用 click 工具，以一次性 popup_token 明确选择截图坐标系。

## 约束

- 不按同 PID 猜测普通兄弟窗口，不合成主窗口和弹层的坐标。
- 弹层点击只允许已交付截图对应的单次左键前台点击；不激活主窗口；再次验证根窗口、前台、弹层 PID/几何和系统鼠标接收者。
- token 30 秒过期，下一次观察或其他工具调用失效，任何点击尝试均消耗。
- 投递或回读失败保留未知结果，不自动重放。
- 不改变 cloud 授权策略、模型工具数量或全局 drag/scroll 权限。
