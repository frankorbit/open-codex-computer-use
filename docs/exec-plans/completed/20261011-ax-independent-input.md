# AX 缺失时的后台输入与纯文本粘贴

## 目标

修复 fork 0acce3f 将显式 sky_key 也强制要求 AXFocusedUIElement 的回归。默认 auto 保留实时 AX 焦点保护；显式 sky_key 校验进程生命周期和窗口归属，在合成 key-window 状态内定向投递。新增 macOS paste_text/app.paste 纯文本扩展，恢复剪贴板且不覆盖并发复制，不声称这是上游现有 API。

## 约束

不改变前台、鼠标策略，不自动重放未知输入。上游参考 3cfe4b1；Codex 样本证明视觉输入路径可行，但不能推断闭源投递细节。剪贴板共享状态无系统 CAS，恢复使用 changeCount 和私有所有者标记。按键异步投递需截图验收，不以工具返回作为业务成功。
