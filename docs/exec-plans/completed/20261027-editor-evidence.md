# 编辑语义与保存核验修复

## 目标与边界

防止把事项行的完成动作当作打开详情，保留查询中的 AX Help；保存核验必须区分草稿、当前详情与最终持久值。保持输入失败、权限、取消和超时停止规则，不重放实机操作。

## 已确认事实

- 实际会话收到旧时间/旧备注与背景草稿冲突，最后未重新打开详情却报告成功。
- 任务自行收尾，非预算或权限停止。
- 点击路径允许整行/单元格选择子控件动作；具有完成语义的全宽容器未被仅针对紧凑侧按钮的过滤器覆盖。
- 日志没有保存实际 AX 路由，不能唯一归因哪一次点击导致完成状态。

- [x] 原生预检阻止具有完成语义的复合行目标，明确控件保留原路。
- [x] query 保留 Help，原生/Runtime/云端入口回归保留冲突证据与停止规则。
- [x] 全量测试、diff review，记录模型行为与自动化测试的证据边界。

## 风险

AX Help 是本地化的非完备提示，防护不能被当作通用意图识别；保存核验模型策略也不等于确定性成功判定。完成代码测试后仍需单独实机验收。
