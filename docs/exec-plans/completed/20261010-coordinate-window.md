# 无 AX 区域的坐标点击

## 范围与决策

将窗口身份、几何及同 App 遮挡验证独立于 AX 命中。无 AX 元素和未实现查询允许在有效窗口上执行鼠标输入；通信失败、窗口不匹配或过期则拒绝。

左键单击/双击默认复用 sky_click 的窗口定向路径；其他鼠标按钮保持 app_post。显式启用全局指针时保留 global，但加完整点击点遮挡验证。只在输入前选路，执行失败不重放。

- [x] 新增独立窗口验证、AX 错误分类、真实 service 入口及前后两次验证回归。
- [x] Swift 非 live / Node 测试、独立复审。
- [x] fork 修复及回归完成；宿主按发布的不可变 revision 集成，真实 GUI 仍由用户验收。

仅 sky_click 允许后台或跨 Space 的鼠标输入。auto 的 app_post 路径还要求目标是前台 App 的聚焦窗口且点击点无遮挡，否则输入前拒绝，避免 PID-only 事件误投同进程其他窗口。显式 app_post API 不变。
