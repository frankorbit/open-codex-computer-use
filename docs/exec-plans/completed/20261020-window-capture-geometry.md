# 完整窗口截图与坐标输入契约

## 目标和边界

修复部分出屏截图被按完整窗口拉伸换算的问题，补齐多显示器和缩放回归。
不修改输入投递机制，不放宽权限、取消、超时及未知结果停止规则，不重放任何已发送的操作。

## 方案

- 仅完整包含于一个 CG 显示器的窗口可尝试硬件截图，并验证比例；其他情况使用 ScreenCaptureKit 独立窗口捕获。
- SCK 只接受窗口 frame、过滤器内容尺寸与原窗口一致的结果；使用过滤器自身缩放。
- 捕获失败不返回部分图；坐标输入必须具有可解码、比例一致的截图和图内有限坐标。
- Today 的 JS 包装层在 native 请求前拒绝无效 click target，不纠正或重试。

## 风险和验收

出屏/跨屏捕获可能比硬件截图慢；SCK 无法确认完整覆盖时保留 AX 状态并拒绝坐标输入。
通过生产捕获选择函数、生产 click 服务及 Today runtime 的回归验证。
真实 WPS 验收在发布 fork 修复、更新宿主 pin 并重新编译后进行，不能用源码测试代替。
